# QueueSync UI Direction

QueueSync is designed around the principle of **live time made visible**. Its recurring live-flow rail signals queue movement, current position, and operational truth without fabricating data. The visual system uses a calm blue-white base for trust and a contained teal signal for real-time availability, live states, and primary actions.

Customer experiences remain spacious and reassuring, while merchant experiences prioritize operational clarity. Empty states explicitly explain which real-world action will create the first usable record, chart, or queue view.
